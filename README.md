## About

I'm a software engineer and Informatics student at the University of Edinburgh. Most of my repositories are smaller side-projects, dating back to 2019 (scary). See my website and blog at [pedley.org](https://pedley.org) to learn more about me.

Currently working on [hatch](https://github.com/alecks/hatch) in my free time, as I found that AI was somewhat waning the fun in software engineering (although there is fun in the productivity it brings). `hatch` is a CLI tool to create server *definitions* based on active system services, symlinked configurations, setup commands run, etc., and reproduce these definitions on other machines.
